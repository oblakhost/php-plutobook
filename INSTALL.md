# Installing PlutoBook for PHP

For most setups:

```sh
pie install oblakhost/ext-plutobook
```

Step-by-step instructions for every platform are on the documentation site:
**[php.plutobook.dev/install](https://php.plutobook.dev/install)**

- [Debian and Ubuntu](https://php.plutobook.dev/install/debian-ubuntu)
- [RHEL, AlmaLinux, Rocky Linux and CloudLinux](https://php.plutobook.dev/install/rhel)
- [cPanel (EasyApache 4)](https://php.plutobook.dev/install/cpanel)
- [Other Linux distributions](https://php.plutobook.dev/install/other-linux)
- [Windows](https://php.plutobook.dev/install/windows)
- [Building from source](https://php.plutobook.dev/install/from-source)
- [Troubleshooting](https://php.plutobook.dev/install/troubleshooting)

The same pages are in [`docs/install/`](docs/install/) in this repository.
